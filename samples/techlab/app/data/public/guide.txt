TechLab Registry | 개발자 가이드
팀의 빌드를 더 빠르게

TechLab Registry는 팀에서 함께 쓰는 CLI, SDK, 라이브러리와 디자인 자산을
한곳에서 찾기 위한 아티팩트 카탈로그입니다. 패키지의 이름, 종류, 현재 버전을
확인하고 필요한 항목을 검색할 수 있습니다.

1. 카탈로그 살펴보기

홈 화면에서 여섯 개의 아티팩트를 확인합니다. 종류 필터는 cli, sdk,
library, asset 중 하나를 사용하며, 검색어는 이름에 적용됩니다.

  Atlas CLI          cli      1.4.0
  Beacon SDK         sdk      2.1.0
  Cobalt Parser      library  0.9.3
  Delta Theme        asset    3.0.1
  Echo Logger        library  1.8.2
  Foxtrot Build Kit  cli      4.2.0

2. API로 조회하기

카탈로그를 도구에서 조회하려면 다음 GET 요청을 사용합니다.

  GET /api/products
  GET /api/products?q=Beacon
  GET /api/products?category=library

응답의 items 배열에는 id, name, category, version이 들어 있습니다.
검색 미리보기 화면은 /search/preview?q=검색어에서 열 수 있습니다.

3. 공개 문서와 상태 확인

  GET /api/files?name=guide.txt
  GET /api/files?name=release-notes.txt
  GET /health

가이드와 릴리스 노트는 읽기 전용 텍스트로 제공됩니다. /health의 status가
ok이면 로컬 카탈로그 프로세스가 요청을 받고 있다는 뜻입니다.

실습 환경 안내

이 인스턴스는 로컬 보안 실습용입니다. 패키지, 버전, 문서와 기타 레코드는
모두 synthetic 데이터이며 실제 배포 파일이나 고객 정보를 제공하지 않습니다.
127.0.0.1에서만 사용하세요.
