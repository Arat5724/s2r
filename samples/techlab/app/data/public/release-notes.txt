카탈로그 1.0.0 — 첫 공개 버전

이번 버전에서는 팀에서 공통으로 확인할 수 있는 아티팩트 목록과 검색
화면을 제공합니다. 홈 화면에서 종류별로 목록을 좁히고 이름으로 찾을 수
있습니다. 각 항목의 현재 버전을 한눈에 확인할 수 있습니다.

등록된 아티팩트

- Atlas CLI 1.4.0: 반복 작업을 정리하는 명령줄 도구
- Beacon SDK 2.1.0: 애플리케이션 통합용 개발 키트
- Cobalt Parser 0.9.3: 구조화된 입력을 다루는 라이브러리
- Delta Theme 3.0.1: 화면 구성에 쓰는 디자인 자산
- Echo Logger 1.8.2: 실행 기록을 남기는 라이브러리
- Foxtrot Build Kit 4.2.0: 빌드 작업용 명령줄 도구

개발자용 경로

- GET /api/products: 전체 목록 및 q, category 검색
- GET /search/preview: 검색어 미리보기
- GET /api/files?name=guide.txt: 개발자 가이드
- GET /health: 서비스 상태

실습 환경 안내: 이 릴리스 노트와 모든 패키지 정보는 synthetic 데이터입니다.
실제 소프트웨어 배포나 운영 변경 이력을 나타내지 않습니다.
