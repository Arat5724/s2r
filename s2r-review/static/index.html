    CHOOSE WHAT TO VERIFY

    검증할 시나리오와 요청 범위

    시나리오에 필요한 엔드포인트를 제외하면 해당 검증도 차단됩니다.

    코드만으로 검증할 수 없는 항목과 패키지 공지는 요청 없이 검토 기록에 남깁니다.
    조회 버튼을 누르면 고정된 패키지 이름·버전이 OSV로 전송됩니다. 공지는 수동 검토 후보로 표시합니다.

    시나리오

    카테고리별 일괄 선택은 시나리오만 바꿉니다. 요청할 엔드포인트는 오른쪽에서 별도로 허용하세요.

    엔드포인트 / 메서드

    체크된 항목 중 실행 가능한 시나리오에 필요한 요청만 허용합니다.

    선택 범위를 저장한 다음 운영 검증으로 이동하세요.

    OBSERVE THE DEPLOYED SERVICE

    선택한 범위에서 취약 동작 확인

    AI가 시나리오별 기준값·후보값을 만들고, 앱이 선택한 엔드포인트의 메서드·경로와 진단 입력을 검증한 뒤 운영 서버의 두 응답을 비교합니다. Python 재검증 스크립트도 제공됩니다. 관찰 결과는 실제 보낸 요청에 관한 근거이며 모든 악용 가능성을 증명하지는 않습니다.

    본인이 관리하는 테스트 서버의 origin을 입력하세요. 경로·인증정보·쿼리 없이 프로토콜, 호스트, 포트만 사용합니다.

    실행 경계

    선택한 엔드포인트의 메서드·경로로 시나리오당 최대 두 번 요청합니다. 대상 서버·경로·메서드는 OpenShell 정책으로 묶고 리다이렉트를 따르지 않으며 인증정보와 쿠키는 보내지 않습니다. 진단 입력은 쿼리 또는 최대 512바이트의 JSON 본문 한 필드로 전달합니다. 메서드와 관계없이 서버 상태가 바뀔 수 있으므로 본인이 관리하는 테스트 환경에서만 실행하세요. 요청 계획을 검증하지 못한 항목은 실제 요청 없이 이유를 표시합니다.

    검증 결과

    실제 응답과 코드 근거를 연결한 조치방안을 확인하세요.

    TURN FINDINGS INTO ACTION

    코드 근거와 조치방안

    AI가 제안한 파일별 수정 diff는 원본 줄과 변경 범위를 검증한 뒤 표시합니다. 삭제 줄은 빨강, 추가 줄은 초록입니다. 원본 소스는 자동으로 변경하지 않습니다.

    범위·관찰 결과·조치방안을 하나의 기록으로 보관하세요.

    A TRACEABLE RECORD

    통합 리포트

    분석 소스, 선택 범위, 실제 검증 결과와 남은 확인 사항을 함께 저장합니다.

    패키지 공지 조회

    조회 버튼을 누르면 PyPI·npm·Maven·Packagist의 정확히 고정된 패키지 이름과 버전이 OSV에 전송됩니다. 조회 기록이 없어도 안전성 보증이 아닙니다.

    EXECUTION BOUNDARY

    선택한 범위로.

    분석마다 별도 OpenShell 샌드박스를 만들고 선별한 원본 소스 파일을 각각 읽기 전용으로 연결합니다. OpenShell 파일 정책은 그 파일이 있는 `/source`만 읽도록 허용합니다.

    소스
    /source · 선별한 원본 파일만 존재, 읽기 허용·쓰기 차단
    입력
    /input · 파일 목록과 해시만 전달
    출력
    /output · 분석·검증 결과 저장
    네트워크
    분석은 모델 경로, 운영 검증은 선택한 서버·엔드포인트 메서드·경로만 일시적으로 허용

    실행 전마다 허용 파일 읽기, 정책 밖 경로 읽기 차단, 원본 쓰기 차단, 출력 쓰기를 확인합니다. 운영 요청이 끝나면 임시 정책을 제거합니다. 운영 요청 자체는 대상 서비스의 상태를 변경할 수 있습니다.

    호스트 앱은 선택할 파일과 시작 시점 해시를 기록합니다. 코드 안의 비밀값을 완전히 검출하는 기능은 아닙니다.
